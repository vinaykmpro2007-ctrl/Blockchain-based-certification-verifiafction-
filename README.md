
# CertiChain - Blockchain-Based Certificate Verification System

A secure platform for issuing and verifying digital certificates using blockchain technology, SHA-256 hashing, and QR codes.

## Project Objective
To prevent certificate forgery and provide secure, transparent, and reliable certificate verification.

## Technologies Used
- HTML, CSS, Bootstrap 5
- JavaScript
- Python, FastAPI
- SQLite
- Solidity
- Ethereum
- ethers.js
- QR Code Generation


## Main Features
- Secure admin login
- Digital certificate generation
- Unique certificate IDs
- PDF certificate downloads
- QR code generation
- Blockchain-based certificate registration
- SHA-256 hash verification
- Certificate revocation
- Public certificate verification
