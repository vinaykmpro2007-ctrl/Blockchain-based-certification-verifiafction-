How verification works

Three steps, usually under ten seconds.

  1. 1

    Find the ID

    Every certificate and document carries a unique ID and a QR code that contains it.

  2. 2

    Enter, scan or upload

    Type the ID, scan the QR code with your camera, or upload the PDF you were sent.

  3. 3

    Read the result

    Green means valid. Red means the issuer revoked it. Compare the name and institution with what you were given.

Why CertiChain

Built so a forged or withdrawn certificate does not pass as genuine.

Issued only by the institution

Only signed-in administrators can issue records, and only under their own institution's name.

Revocation shows instantly

If an institution withdraws a record, the next check shows it as revoked, with the date.

Private by design

Aadhaar and PAN numbers are never stored in full. Verifiers see only a masked version.

Fast on any device

Works in a phone browser. No app to install and no account to create.
